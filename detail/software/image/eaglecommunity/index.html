Eagle 资源社区是什么？

Eagle 资源社区是 Eagle 官方维护的中文设计资源社区，域名和中国区站点都与 Eagle 客户端分开：客户端在本地管素材，社区负责找素材、找灵感、找工具。资源以 .eaglepack 素材包形式提供，下载后导入 Eagle 即可使用。

站点按六个设计领域组织资源：UI 设计 477 个、平面设计 574 个、插画设计 687 个、游戏设计 553 个、室内设计 110 个、工业设计 45 个，合计约 2400 个（数量随投稿持续增长）。另有三块内容：插件中心（Eagle 的功能扩展）、设计导航（收录 13 个分类共 1160 个设计网站）、优秀作者（按领域和下载 / 收藏 / 浏览排行的贡献者列表）。

Eagle 资源社区如何使用？

  1. 先进资源广场：从首页或「资源广场」选出六个领域之一，再点细分标签收窄范围；搜关键词也行。
  2. 看清两个字段再下载：一是「版权信息」（免费商用，还是仅供学术及教育目的），二是「资源类型」（素材包才有文件，灵感参考是图集）。
  3. 下 .eaglepack 文件：详情页点「下载资源」，得到的是 Eagle 专用素材包，不是压缩包，普通解压软件打不开。
  4. 导入 Eagle：装好客户端后双击，或把文件拖进素材库窗口，按提示导入。多数资源包已按样式、分类分好文件夹，导入后直接挑图；像图标这类还会按 Outline、Solid、Mini、Micro 分好子文件夹。
  5. 收藏与投稿要注册：注册用邮箱或 Google 账号，用于收藏、评论、投稿和稿件投诉，下载本身不需要账号。
  6. 发现侵权可投诉：详情页有「稿件投诉」入口，官方承诺收到后处理。

Eagle 资源社区是否有会员制及特权？

没有会员制，也没有付费档位、积分或额度限制：全站资源免费下载，站点导航与用户协议里都不出现「会员」「VIP」「收费」「付费」这类收费条目，注册账号也不产生费用。

需要分清三件事：

  • 社区免费，但素材版权分两类。一类是「可免费商用」，允许用在个人和商业作品里；另一类是「仅供学术及教育目的」，只能在 Eagle 中查看、参考、学习，商用要自行联系作者。上传者对自己的声明负责，商用前务必看详情页的版权字段。
  • 插件中心按「免费 / 部分免费 / 付费」筛选，付费那一档基本是空的，实际以 Eagle 官方免费插件为主。设计导航里标注的「部分免费」「付费」指的是收录的外部网站自己的定价，与社区收费无关。
  • 用户协议划了三条使用红线：不得把站内内容以素材包或其它形式转卖；不得拿站内内容做素材管理工具、素材库这类竞品的资产；不得用脚本自动批量下载。违反会被移除内容或封号。
