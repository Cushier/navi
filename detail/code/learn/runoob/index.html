菜鸟教程是什么？

菜鸟教程（runoob.com）是中文编程教程站，标语是「学的不仅是技术，更是梦想」。内容按 12 个大类组织，教程数量在 100 门以上：Python 与数据科学、AI 与智能开发、前端开发、后端开发、数据库、移动开发、DevOps 与工程化、编程语言、计算机基础、XML 与 Web Service、.NET、网站建设。同一门语言常常给多个版本（Python3 与 Python2、Bootstrap4 与 Bootstrap5、Vue 与 Vue3、jQuery 与 jQuery UI），读者不用在旧版教程里自己换算。

写法上偏向「最小示例讲清概念」：每节正文不长，配一段能在线运行的代码，页尾还挂着读者写的笔记——有人补充原理，有人记录踩坑，等于教程自带一块社区注释区。站内没有会员入口，教程、实例、测验都是免费看。

另外要提一句：站里的「菜鸟工具」已经不挂在 runoob 域名下，实际入口是独立站 jyshare.com（c.runoob.com 会跳过去），同一个团队做的。

菜鸟教程可以做什么？

  • 从零学一门语言：C、C++、Zig、Scala、Ruby、Perl、Lua、Dart、汇编、Verilog 都在「编程语言」类里；Python 一侧还分出 FastAPI、Flask、Django、NumPy、Pandas、SciPy、Matplotlib、Jupyter Notebook、量化交易这些专题。
  • 跟进新东西：AI 与智能开发类目下有 AI Agent、AI 应用案例、Vibe Coding、Claude Code、Codex、OpenCode、Skills、Ollama、Hermes Agent、DeepSeek Harness、LangChain、TensorFlow、PyTorch、OpenCV 等，更新节奏比多数中文教程站快。
  • 在线跑代码：代码块下面有「运行实例」，点开能在浏览器里直接改、直接看输出，不必先装环境。
  • 做测验：每门教程末尾有配套测验，学完能立刻自查。
  • 看别人的笔记：每个教程页底部是读者笔记区，按点赞排序，常见的「为什么这行要这么写」在这里基本都有人答过。
  • 查参考手册与面试基础：数据结构与算法、设计模式、正则表达式、HTTP、TCP/IP、网络协议这些计算机基础内容单独成类；语言手册与标签手册也齐。
  • 用菜鸟工具干活：正则在线测试、JSON 格式化 / 解析 / 转义 / 差异对比、XML 格式化、时间戳转换、颜色与取色器、多语言在线编译（PHP、Python3、Java、C、C++、C#、Ruby、Scala 等）、SQL 在线生成、AI UML 图生成器、PDF 工具箱、Excel 数据清洗与脱敏、Markdown 转图片，还有一批以 Excel 为主的小工具。
  • 手机上接着看：m.runoob.com 是移动版，教程章节与桌面端一致。

菜鸟教程如何使用？

  1. 从首页选大类：首页按 12 个类别铺开，先定位到方向（比如「前端开发」），再挑具体那门课，比直接搜索快。
  2. 跟着左侧章节树走：教程目录在左侧，从简介、环境搭建往下，节与节之间是递进的，别跳着读。
  3. 看到代码就点「运行实例」：在线编辑器能改参数、看输出变化，这是这个站比纯文档型教程好用的地方。
  4. 学完做测验：测验错了回对应小节补，比通读一遍有效。
  5. 页尾笔记值得翻：遇到「明明照抄示例还是报错」的情况，先看笔记区，大概率有人写过同样的问题。
  6. 写笔记属于登录功能：阅读笔记不需要账号，写自己的笔记要登录；登录不解锁任何教程内容。
  7. 工具单独去：需要格式化 JSON、调正则、转时间戳、临时编译一段代码，直接进菜鸟工具（c.runoob.com，实际站点是 jyshare.com），不要以为那是第三方镜像站。

菜鸟教程是否有会员制及特权？

没有会员、VIP、订阅或付费课程。教程、参考手册、实例、测验、在线运行、菜鸟工具全部免费，不登录就能用，站内也没有「升级解锁」的入口。成本靠页面广告覆盖，所以正文旁边有广告位属正常现象。

登录在这个站只有一件事的作用：写笔记。看教程、跑实例、做测验、用工具都不需要账号，也没有学习进度、完成证书、作业批改这类功能。

和 W3School 的差别（两个常被一起推荐）：菜鸟教程科目更多、跟进新框架更快、多了读者笔记区和一整套在线工具；W3School 更接近教科书的规整路线，章节顺序更线性、手册更系统。两个都免费、都不需要登录，做入门教材时可以互补——按体系读用 W3School，查具体框架用法和跑代码用这里。

要注意的一点：菜鸟工具的域名是 jyshare.com，和 runoob 不同，但页面底部挂着同一团队的账号，功能也互通，不是仿站。收藏时把两个域名分开记，避免以后找不到。
