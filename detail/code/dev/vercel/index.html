Vercel是什么？

Vercel 是一个面向前端与全栈项目的云部署平台。核心动作极简：把代码推到 Git 仓库，平台自动拉取、构建、发布到全球 CDN，几分钟后拿到一个可访问的网址。

2015 年由 Guillermo Rauch 在旧金山创立，最初叫 ZEIT；2020 年 4 月 21 日更名 Vercel。Rauch 本人是 Next.js 的三位共创者之一（另两位是 Tim Neutkens、Naoyuki Kanezawa），也是 Socket.IO 的作者，所以 Vercel 对 Next.js 的支持是原生的——框架的新特性往往在平台上第一天就能跑。

值得留意的是定位变化。早年主打 Jamstack 与「前端云」，官网现在挂的是 Agentic Infrastructure，能力范围扩到 AI 应用与 Agent 运行时：沙箱虚拟机、模型网关、持久化后端都在同一套平台里。对普通用户来说，前端托管仍然是最好用的那部分。

Vercel可以做什么？

  1. 推送即部署：连上 GitHub、GitLab 或 Bitbucket 仓库，之后每次 push 自动触发构建，不用自己搭 CI 服务器。
  2. 预览部署：开一个分支或提一个 PR，平台自动生成一个独立网址，改动先在那上面看效果，确认没问题再合进主干。团队评审靠的就是这个。
  3. 全球 CDN：静态资源分发到各地节点，自动签发 HTTPS 证书，自动压缩、缓存；流量突增有防护。
  4. 服务端能力：Serverless Functions 与 Edge Functions，写一个文件就是接口，不必单独买服务器；Fluid compute 让函数复用实例，冷启动更少。
  5. 框架通吃：Next.js 之外，Astro、Vite、Nuxt、SvelteKit、Remix 这些主流框架都能自动识别构建设置，基本不用手工填。
  6. 图片优化与增量生成：内置图片转换和缓存；支持增量静态再生成（ISR），页面可以先给静态版、后台再更新内容。
  7. 数据与观测：Web Analytics 看访问量，Speed Insights 看真实用户加载性能，两套在免费档也有额度。
  8. 一键回滚：每次部署都留记录，出问题在部署列表里点回滚，几十秒回到上一个正常版本。
  9. 命令行与 API：vercel 命令可以在本地直接部署、拉环境变量；也开放 API 和 MCP，方便接进自动化流程。

Vercel如何使用？

  1. 注册：用 GitHub、GitLab 或 Bitbucket 账号登录，顺带就把仓库授权一起给了。
  2. 导入项目：控制台点 New Project，选一个仓库，平台自动识别框架并填好构建命令和输出目录，直接 Deploy。
  3. 不想连仓库也能传：本地装 CLI（npm i -g vercel），在项目目录跑 vercel，按提示登录后即上传部署。
  4. 绑自己的域名：项目 → Settings → Domains，填域名后按页面给的记录去 DNS 服务商配 CNAME 或 A 记录，生效后自动签证书。
  5. 配环境变量：Settings → Environment Variables，可以分别设给 Production、Preview、Development，密钥别写进代码。
  6. 走预览流程：本地开分支推上去，或直接提 PR，等预览网址生成，验收完再合。
  7. 回滚：Deployments 列表选一个历史版本点 Promote 或 Rollback。

首次用建议先拿一个静态页面跑通「导入 → 部署 → 绑域名」这条链路，确认 DNS 生效，再去接函数和环境变量。Vercel 的免费档对个人项目够用，但配额和用途都有边界，下面一节写清楚。

Vercel是否有会员制及特权？

有分档，但不是个人会员制。 三个档位，免费的那档有硬性用途限制。

Hobby（免费，$0）——只限个人非商业用途：

  • 项目 200 个，单项目域名 50 个
  • 每天最多 100 次部署
  • 带宽 100GB / 月，CDN 请求 100 万 / 月
  • 函数调用 100 万 / 月，函数单次最长 300 秒
  • 构建机器 2 vCPU / 8GB 内存
  • 运行日志保留 1 小时，Web Analytics 5 万事件 / 月
  • 超出配额不是扣费，是功能暂停，多数要等 30 天恢复

Pro（$20 / 开发者席位 / 月，含 $20 用量额度）：

  • 项目不限，每天 6000 次部署，带宽 1TB / 月
  • 团队协作、Viewer 席位免费、Spend Management 设预算上限
  • 日志保留 1 天，密码保护、WAF 规则数上调
  • 新团队有 14 天试用，付费 Pro 团队另有首年域名优惠

Enterprise：定制报价，99.99% SLA、单点登录与目录同步、多区域计算与故障转移、专属支持。

最该记住的一条：Hobby 档明确限制为个人非商业使用，官方把商业用途定义为「任何参与项目生产的人借此获得经济收益」的部署，明确列举的情形包括：向访客收款、宣传销售产品、收钱帮人建站更新、以联盟推广链接为主要目的、站内挂广告（含 Google AdSense 这类广告平台）。接受捐赠不算商业用途。做个人博客、作品集、学习项目没问题；一旦挂广告或接单卖货，必须换 Pro 或 Enterprise。

另外两类限制与档位无关，免费和付费都受同一套公平使用政策约束：代理与 VPN、媒体热链托管、爬虫、加密挖矿、CPU 密集型接口（比如跑机器学习推理）、压力测试，都不允许放在上面。
