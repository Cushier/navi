Cloudflare是什么？

Cloudflare 是一家做全球云网络的公司，官方网站有中文版（cloudflare-cn.com），账号体系和全球站是同一套。核心思路是让网站不直连用户，而是先经过它分布在全球的节点：用户就近访问、攻击在边缘被拦掉、源站只处理真正的请求。

起点挺特别。2004 年 Matthew Prince 和 Lee Holloway 做了个项目叫 Project Honey Pot，专门追踪垃圾邮件是从哪儿收集到邮箱地址的；后来越来越多站长提出同一个要求——别只记录，直接拦住。2009 年 Prince 在哈佛商学院遇到 Michelle Zatlyn，三人把这件事做成了公司。2010 年 9 月 27 日在 TechCrunch Disrupt 上正式发布，当时打的就是「免费、基于 DNS、五分钟配好」这套牌。2019 年 9 月 13 日在纽约证券交易所上市。

规模按官方口径：60 多项云服务；每天阻止约 2340 亿次网络威胁；全球约五分之一的网站由它保护；节点覆盖 125 多个国家和地区的 330 多个城市。

今天的能力大致分三条线：连接（Cloudflare One，做远程办公与零信任接入）、保护与加速（WAF、DDoS、机器人防护、CDN）、构建（Workers 等开发者平台，可以跑代码、存对象、放数据库）。中文站首页也把这三条分别列了出来。

Cloudflare可以做什么？

  1. 域名解析：免费 DNS，全球响应快、改记录基本秒级生效，比不少域名商自带的解析好用。
  2. CDN 加速：静态资源缓存到各地节点，源站带宽压力小很多。
  3. 一键 SSL：Universal SSL 自动签发并续期证书，不必自己折腾 Let’s Encrypt。
  4. DDoS 防护：不限量，免费档就开；被打的时候网站不至于直接躺下。
  5. WAF 防火墙：免费档也带官方托管规则集，挡掉常见的扫描、注入、漏洞利用。
  6. 机器人管理：识别爬虫和自动化流量，免费档给基础规则，付费档才有复杂行为分析。
  7. 规则与跳转：免费档 70 条规则加 1 万次批量重定向，够做 301、临时跳转、按路径改缓存策略。
  8. 边缘计算与存储：Workers 写服务端逻辑（免费 10 万请求 / 天），R2 存对象（免费 10GB 且不收出口流量费），D1 是 SQL 数据库（免费 5GB），Images 做图片转换（免费 5000 次 / 月）。
  9. 域名注册：Cloudflare Registrar 按成本价卖域名、不加价，续费也是成本价。
  10. 远程办公接入：Cloudflare One 做零信任，50 人以下免费。
  11. 中国大陆加速：China Network，在境内 30 个数据中心跑，属单独付费项（见下一节）。

Cloudflare如何使用？

  1. 注册并添加站点：登录后点 Add a site，填自己的域名，选套餐——个人站选 Free 就行。
  2. 换成它的 NS：平台会给两条名称服务器地址，去域名注册商那里把 NS 改过去。生效后解析权就交给 Cloudflare 了。
  3. 换 NS 前先核对记录：扫描出来的 DNS 记录一定要逐条检查，尤其邮箱的 MX 和验证用的 TXT。漏一条，邮件就收不到了，这是新手最常踩的坑。
  4. 设好 SSL 模式：SSL/TLS 选 Full (Strict) 最稳。选 Flexible 而源站又强制 https 时，会出现「重定向次数过多」的死循环。
  5. 按需配缓存与规则：缓存级别、页面规则、批量重定向都在 Rules 里，先只加一条试试，别一次铺满。
  6. 要用开发者能力再开：Workers、R2、D1 在控制台单独创建，和主站共用一套账号。
  7. 想让中国大陆也快：这一步不是换 NS 就能解决的。要买企业版再加购 China Network 套餐，域名必须有 ICP 备案（页脚要显示备案号），内容还要过京东云审核。三者缺一不可。

先建立正确预期：套上免费版之后，境外访问通常变快，中国大陆访问不一定——免费档走的是境外节点，跨境链路反而可能更慢。境内提速是付费项，且门槛不低。

Cloudflare是否有会员制及特权？

有分档，按站点按月计费，四档：

  • Free（$0）：定位是个人或爱好者项目、非业务关键用途。含免费 DNS、CDN、不限量 DDoS 防护、Universal SSL、托管 WAF 规则集、70 条规则 + 1 万次批量重定向。
  • Pro（$20 / 月，年付；月付 $25）：规则升到 225 条 + 2.5 万次重定向，加无损图片优化（平均缩 35%）、AMP/Mirage 移动端优化、基础机器人分析。
  • Business（$200 / 月，年付；月付 $250）：450 条规则 + 5 万次重定向，100% 正常运行时间 SLA 与 10 倍服务积分，完整 WAF 托管规则、PCI DSS 4.0 合规，工单 + 聊天支持。
  • 合约 / Enterprise（定制，年付）：2700 条规则 + 100 万次重定向、25 倍服务积分、24×7 电话支持；China Network 只有这一档能加购。

单卖的附加项（不升级套餐也能买）：Argo 智能路由 5 美元 / 月起、负载均衡 5 美元 / 月起、Stream 视频 5 美元 / 月起、高级证书管理 10 美元 / 月、Cache Reserve 按量；WordPress 站可以单开 APO，Free 档 5 美元 / 月，Pro 以上含。Cloudflare One 另有独立档位：50 用户以下免费，超出按 7 美元 / 用户 / 月。

中国网络的门槛要说清：它不是套餐里的一个开关，而是一份单独订阅。前提是已有 Enterprise 计划，加购 China Network 套餐并签署中国服务补充条款；每个顶级域名都要有 ICP 备案；内容需要京东云逐域名审核，可以批准也可以拒绝；境内对外服务还必须支持 IPv6（平台会自动开）。Cloudflare 自己并不持有工信部牌照，境内业务是持牌的京东云在运营。

给个人站的判断：静态博客、个人作品集，Free 档完全够，最值钱的是免费 SSL 和不限量 DDoS。Pro 的差值主要在规则数、图片优化和客服响应，不是刚需。真正为了中国大陆速度花钱，路径只有企业版 + 中国网络，一年下来不是小数目——预算有限时，更实际的做法是把源站放在境内、备案走国内 CDN，而不是给境外站套 Cloudflare 再指望它变快。
