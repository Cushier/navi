象棋AI是什么？

这个站的首页标题写着「象棋AI在线分析 - 皮卡鱼象棋在线」，说白了就是皮卡鱼（Pikafish）的网页版：把中国象棋最强的开源引擎搬到浏览器里，摆一个局面，它给你算最佳着法。

皮卡鱼的来路值得说清。它是国际象棋最强开源引擎 Stockfish 的中国象棋分支——搜索那一层沿用 Stockfish 打磨了十几年的算法（哪些分支值得深挖、哪些可以安全剪掉），棋盘从 8×8 换成 9×10，加河界、加九宫，走法几乎没一处相同，于是评估部分整个重写。

重写的方式是 NNUE：用一个在数百万局面上训练出来的小型神经网络，替代传统引擎那套「车值多少分、过河兵值多少分」的人工规则表。这种网络每走一步只要重算其中很小一部分，所以引擎每秒能跑几百万个局面。皮卡鱼另带一个权重文件，引擎本体不含它——这也是很多人第一次用引擎时踩的坑。

棋力上，皮卡鱼在象棋引擎天梯榜上长期居首。官网用版本自测数据说话：2026.09.25 与上一版对打 2000 局，615 胜 850 和 535 负，胜率 52%，ELO +17.6。代码完全公开，按 GPL v3 授权，非商业使用永久免费。

网页版最大的好处是免安装。同一个引擎也有 Windows、Linux、macOS、安卓的本地版本，网页版适合临时复盘、随手看局面，不用先下几十兆的包。

象棋AI可以做什么？

  1. 分析任意局面：自己摆棋、粘贴 FEN，或者直接导入一盘棋谱，引擎立刻给分。
  2. 看引擎推荐：给出几条主要变化和各自主的分数，想算深就多等一会儿，算得越久越准。
  3. 查云库，秒出结论：云库来自象棋云库（chessdb.cn），存的是海量局面事先算好的着法与分数。引擎是现场算，云库是查现成，冷门局面可能没收录，但主流开局和中残局基本一问就有。
  4. 残局直接给答案：云库对残局会标出「红方 n 步杀」「黑方 n 步杀」或「和棋」，这类已经算清楚的局面不用等引擎。
  5. 看大师怎么走：云库面板能切到大师谱，显示当前局面下大师实战的红胜、和、黑胜比例，以及下一步大家都走什么，还能按棋手、赛事、年份、结果筛出具体对局。
  6. 复盘整局：着法列表可以点着跳，评估曲线能看出优势是怎么一点点转移的。
  7. 导入各种棋谱：图片识别、PGN / XQF / CBL / CBR / DhtmlXQ 等文件、或者直接粘文本和链接，常见格式都认。
  8. 跟它对下：站内有对弈模式，想找虐或者想练都可以。
  9. 存下来接着看：工具栏有保存/分享，网页版登录后棋谱存账号里，换设备也能找回来。

象棋AI如何使用？

  1. 打开就等加载：第一次进要下权重文件，比后续慢，等进度走完再动手。
  2. 先摆局面：从开局摆、从残局摆，或者粘一串 FEN 都行。摆完引擎自动开始算。
  3. 看分数别看错视角：引擎默认给的是胜率分数（Elo 口径），不是「红方领先几分」那种。分数往上走表示走棋方占优，别看反。
  4. 切云库对比：电脑上引擎和云库两栏并排显示；手机上点分析面板上的标签名切换。云库里点某一行，棋盘上就直接走那一步。
  5. 遇到「未入库局面」：说明云库没收录这个局面，看引擎那栏就行，不是出错。
  6. 导入棋谱复盘：把弈城、天天象棋导出的棋谱文件丢进去，或者拍照识别，逐手看引擎的评判。
  7. 想让 AI 让棋：引擎支持 UCI 限强，开 UCI_LimitStrength 再配 UCI_Elo，1280 到 3133 一档档往下调（对应 Skill Level 0 到 19）。新手陪练用这个，别直接跟满血版下。
  8. 引擎起不来怎么办：先刷新重试，换网络再试；反复失败可以去官方反馈群报一声，首页就挂着入口。
  9. 存棋谱：网页版保存要登录，只想本地留着就用 App 版，不登录也能存这台设备上。

象棋AI是否有会员制及特权？

没有会员制。 分析、查云库、对弈都不收费，也不需要登录；唯一和账号有关的是「把棋谱存进账号」，网页版要登录，App 不登录也能存在本地。

真正要留意的不是价格，是授权：

  • 引擎按 GPL v3 开源。自己用、教学用、非商业用途永久免费；要嵌进商业产品、二次分发，就得按 GPL 的规矩来，这是法律边界而不是收费门槛。
  • 云库是公开数据库，联网查询不用登录，也没有次数限制的说法，但它同样不是付费服务。
  • 没有「付费解锁更深」这种设计。能算多深取决于你的设备和愿意等多久，不取决于钱包——这一点和很多商业象棋软件正好相反。

需要提醒的是，这站只是分析器，不是教练：分数和最佳着法都给，但「为什么」不解释。想弄懂棋理，还得自己看大师谱、或者找人讲。真要提高，把引擎的分数变化和大师谱的实际选择对着看，比单纯追着最高分走有用得多。
